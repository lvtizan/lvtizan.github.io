关键词研究：找到老外真正在搜的词

发布于 2026-08-05 · YOYANT 远洋数字

这是整个 SEO 里最该先做、也最容易做错的一步。词选错，后面写多少页、发多少内容都白费——你在拼命优化一个老外根本不会去搜的词。上一篇讲了获客链路，这篇解决其中最要命的"被搜到"这一环的前提：搜什么。

最常见的错：用你的词，不是买家的词

外贸人做关键词，十有八九栽在同一个坑：拿自己的产品术语、内部型号、甚至中式英语去当关键词。你天天叫它"高精度数控回转工作台"，翻成英文塞进标题，觉得很专业——可海外采购商在 Google 里敲的可能是 cnc rotary table supplier 或者 4th axis rotary table for milling。你和买家用的是两套语言，词对不上，再高的专业度也照不到他面前。

关键词研究的全部意义，就是把"你怎么描述产品"翻译成"买家怎么搜产品"。别从产品说明书出发，从一个采购商的处境出发：他有个什么问题、要采购什么、会怎么开口。

买家意图分三种，外贸站主攻其中一种

意图类型典型词对外贸站的价值
信息型what is a rotary table / how does it work低。搜的人多半在学习，不是要买
商业型rotary table manufacturer / supplier / factory / price最高。搜这些的就是要下单的采购商
导航型某个品牌名只对该品牌自己有用

外贸独立站要把有限的力气，压在商业意图词上——带 supplier / manufacturer / factory / wholesale / for sale / price / bulk 这类后缀的词。搜"industrial endoscope manufacturer"的人，和搜"what is an endoscope"的人，商业价值差一个数量级。信息型词可以用博客去覆盖（这是本系列后面会讲的内容营销），但产品页、落地页优先咬住商业词。

不花钱也能挖出真词的几个办法

1. Google 自己就是最好的工具

在 Google 搜索框里敲你的核心词，看下拉自动补全——那都是真人搜过的高频组合。搜完拉到结果页底部看相关搜索（Related searches），再看结果里的 People Also Ask 折叠框。这三处全是免费的真实需求，比拍脑袋强太多。

2. 看同行独立站排在什么词上

找几个做得好的国外同行，看他们的产品页标题、H1、URL 都用了哪些词。他们能排上来，说明这些词既有人搜、又和产品对得上，直接抄思路。

3. 关键词规划师 / 付费工具

Google Ads 的关键词规划师能看大致搜索量和竞争度（有个广告账户就能用）。预算够可以上 Ahrefs、Semrush，能批量看搜索量、难度、同行词。工具是加速，不是前提——很多好词光靠上面两招就够了。

一个反直觉但很重要的判断

别迷信搜索量。B2B 里一个月只搜 10 次、但每次都是真采购商的词，比一个月一万次的泛词值钱得多。

做消费品习惯了追高搜索量，到 B2B 外贸这套失灵。你的客户本来就是一小撮专业采购，词越具体、搜索量越小，往往买家意图越纯、竞争越小、越好排。endoscope 你这辈子都排不上第一页，但 industrial videoscope for turbine blade inspection 这种长尾，搜的人不多，可搜的每一个几乎都是精准客户，而且你有机会真的排到前面。先吃透这些又准又好打的长尾词，再谈大词。

选完词，怎么落到站上

原则就一条：一页锁定一个主关键词，别让一个页面同时想抢五个词，也别五个页面抢同一个词（会自己跟自己打架）。把挑出来的商业词，一个个分配到对应的产品页、方案页上，让页面内容真的围着这个词展开。具体怎么在产品页上落地，就是下一篇（系列 03）的事。

我们给工业内窥镜、石油装备这类技术型产品做站时，第一步永远是把买家真正在搜的词捋出来，再据此定信息架构——而不是先套个模板、事后硬塞关键词。词选对了，后面才谈得上省力。
