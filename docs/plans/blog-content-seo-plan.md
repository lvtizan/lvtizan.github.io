# YOYANT 博客（/resources/）系统化引流规划

> 目标：用内容让 yoyant.com 在"出海建站 / 外贸独立站 / 软件官网设计"这类**买家意图词**上被搜到，
> 把搜索流量导进站内、最终转成询盘。不是刷量，是"真内容 + 真读者 + 站内转化"。
> 现状：`/resources/` 已有 8 篇（这就是你的"博客"，不用另开站——独立站挂链回自己是 PBN，谷歌打）。

## 0. 三条铁律
1. **只打买家意图长尾词**，不碰新站赢不了的大词（"建站""网站开发"是老站+海量外链在占，几个月挤不进）。
2. **每篇文章 = 1 个关键词 + 真价值 + 2~4 条站内链 + 1 个 CTA**。薄文/AI 味/关键词堆砌 = 负分。
3. **绝不新开博客挂链、绝不买链**。要外链，靠好内容被人自然引用 + 去有权重的第三方站投稿带 canonical 回站。

## 1. 结构：主题簇（Pillar–Cluster）
几个**支柱页**（宽主题，锚核心词）+ 一堆**簇文章**（具体问题，锚长尾），簇文章向上链支柱、向下链服务页/案例页。
内链引擎：`簇文章(长尾) → 支柱页(核心词) → /services/*(服务) → /work/*(案例演示) → #contact(询盘)`。

|---|---|---|
| 外贸独立站 / 出海建站 | 外贸独立站、出海独立站、跨境独立站 | /services/web/ + 新建支柱长文 |

## 3. 单篇文章模板（每篇照做）
- **标题**：关键词打头 + 品牌，如「外贸独立站建站要花多少钱？2026 成本拆解 | YOYANT 远洋数字」
- **H1 唯一**，800~1500 字**原创**，给真东西：清单 / 成本区间 / 对比表 / 真实截图 / 踩坑，不写正确的废话。
- **站内链 2~4 条**：向上→支柱/服务页，向下→1 个相关案例演示（带转化）。
- **CTA 1 个**：`获取免费网站诊断` 或 `查看外贸独立站服务`。
- head：Article JSON-LD（author=YOYANT 远洋数字）+ canonical + og(含 og:url) + GA4 `G-0VE5EQQE12`。
- 图片一律过 `scripts/imgctl.py`。可加 FAQ schema 抢 Google 富结果。

## 4. 发文节奏（可持续、批量化）
- **第 1 月**：补 3 个支柱长文 + 6 篇高意图簇文（先把上面 ★ 的做掉）。
- **之后**：稳定 **每周 2 篇**，一次批量写 4~6 篇排期发（别一天堆一堆又断更）。
- 每篇发布即：进 sitemap → GSC「请求编入索引」催收录 → 内链接进相关文章/案例。

## 5. 站外分发（放大器，非外链来源）
每篇好文一稿多投，**canonical 一律指回 yoyant 原文**：
- 国内：知乎专栏 / 掘金 / CSDN（带一条自然回链，不是纯挂链）。
- 海外：Medium / LinkedIn / dev.to（英文版，canonical 回官网）。
- 案例类：Behance / Dribbble 视觉帖 + 文末链官网。
> 价值在"内容被真人看到、有人从自己站主动链你"，X/社媒是引流喇叭（外链多为 nofollow，不传权重），别当外链工具。

## 6. 衡量与迭代（GSC + GA4）
- 每篇盯 GSC：曝光 / 点击 / 平均排名 / 命中的 query。
- 长尾词进前 3 页就**加内链、补内容**推它上首页；完全没曝光的选题换掉。
- GA4 看文章→服务页→询盘的路径，转化好的主题多写。
- 现实预期：长尾几周~两月可上首页；核心大词几月起步、要靠外链积累。
