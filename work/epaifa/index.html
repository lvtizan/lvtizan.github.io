项目概述 · Overview

Epaifa Mall 是为跨境批发商打造的供应链 + 商城一体化移动应用。它把过去分散在采购、仓库、销售、财务之间的动作，收敛进一部手机：老板端一键接单采购、多仓收货入库、逐箱清点与不良品带图上报、按库存量自动补货；作业端拣货出库、发货任务与跨境头程跟踪；交易端多规格阶梯价下单、结账收银（货款 / VAT / COD / 运费 + 现金收款与欠款对账）、退货退款闭环。

库存居于两条链路正中，双向驱动上游补货与下游履约，形成一条可追溯的业务闭环。

Screen Flow · 业务流程连线

一条闭环：从采购到履约

把真实界面按业务走向连起来——上游采购入库补货，下游下单拣货发货，库存居中双向驱动，退货售后回写。横向可滑动查看每一步。

① 供应链后台 · Supply → Stock
↘ 入库异常分支 · 不良品上报（带图凭证）→ 数量回写库存
⟲库存量触发 → 补货建议 → 回到「采购」，形成采购—入库—库存—补货闭环
库存居中 · 双向驱动下游履约
② 交易前台 · Order → Fulfillment
↘ 售后分支 · After-sales
