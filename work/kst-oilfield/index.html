项目概述 · Overview

KST POWER（广州松特机械 / KST Group）是一家做石油钻采、矿山与动力装备出口的供应商，向海外买家成套供应钻机、工业发动机与发电机组。它的痛点很典型：产品是重工业硬装备，海外采购商在下单前只认「型号 + 参数 + 能不能被搜到 + 邮件能不能联系上」，而不是花哨的动效。原来的展示方式散、参数不成表、非中文买家看不懂、搜索引擎也抓不到关键信息。

我们把它重做成一个静态、依赖极少、可被搜索引擎完整抓取的外贸独立站：三条产品线各自成页，每个型号进参数表并带实时搜索；英文为主、中英俄三语内联切换；联系方式、mailto、结构化数据全部静态渲染，保证不跑 JS 的爬虫和社交卡片也能读到。站点已上线 kst-power.com，双通道部署（GitHub Pages + 自有服务器 nginx）。

逐屏看这个站怎么做

全部为 kst-power.com 线上实拍高清截图，点任意一张可全屏查看型号参数表的每一格细节。

01 · 首页 · 一屏说清「做什么、能做多大」

重工业买家没耐心翻介绍，第一屏必须直接回答「你到底供什么」。我们把首页做成三分屏英雄区——发电机组、工业发动机、油田钻采设备并置，每屏压一张实拍大图并直接标出硬指标（发电 10kW–3000kW、钻深 9000m、压力 175MPa）。往下是五大应用场景联图（油田 / 天然气 / 钻井 / 矿山 / 电力）与一排「用数字不用形容词」的能力指标，把选型信心在首屏就建立起来。

02 · 油田钻采设备 · 参数成表 + 型号实时搜索 + 就地询盘

这是全站的核心业务问题：石油钻采装备靠型号和参数成交，买家要的是能快速比对、能被搜索引擎抓到的规格页，而不是图册。油田钻采分钻机 / 修井 / 固井 / 压裂四大类，每类进独立 Tab；每个系列的型号进参数矩阵表——如压裂撬 SYL2500Q 到 SYL8000Q 的电机功率、排量、工作压力、整机重量逐格列清。每张表顶部带实时型号搜索框，买家输入型号即时过滤；表下就是就地询盘入口，看到合适型号当场发起联系，不用跳转。

03 · 工业发动机 · 25+ 机型 + 配套设备对照

工业发动机页面向矿卡、挖机、装载机、钻机与油气钻采作业。上部是康明斯机型图廊（QSK 系列实拍轮播），下部是矿用发动机规格表：型号、排量（3.8–95L）、功率（74–4400hp）、扭矩，外加一列「OEM 配套设备 / 适配机型」——直接告诉买家这台发动机能上别拉斯、小松、卡特、利勃海尔哪些设备，把「选型」和「我这台机器能不能用」一次答完。同样带型号搜索。

04 · 发电机组 · 按品牌分 Tab 的选型逻辑

发电机组买家往往先认品牌，再看功率。所以这页按康明斯 / 卡特彼勒 / 博杜安分品牌 Tab 组织，每个品牌下是完整的机组规格表——机组型号、配套发动机型号、主用 / 备用功率（kVA 与 kW 双列），覆盖 10kW 到 3000kW，另含井场油田机组与钻井动力模块。参数口径与官方一致，专业买家一眼可信。

05 · 三语 · 售后 · 公司背书

面向全球买家，语言是门槛也是信任信号。全站中 · 英 · 俄三语，译文（含导航、正文、参数说明）内联在同一页、按 localStorage 记忆偏好，切换零跳转——下图同一台发动机页的俄语视图即为例证。售后服务页把「选型建议 / 报价交付 / 备件供应 / 双语支持」四项讲透，回答海外采购最担心的「买了之后怎么办」；关于页用 KST Group（成立 2005）背景与卡特彼勒、SJPETRO、别拉斯、康明斯、博杜安等合作品牌建立可信度。

看不见但同样关键的一层：全站静态渲染，联系邮箱、mailto、schema.org 结构化数据全部写进 HTML，保证不执行 JS 的爬虫、Bing 与社交预览卡片也能抓到；配 WebP 响应式图 + LCP 预加载做性能；联系方式与新闻用单一数据源构建脚本一处改、全站同步（含 CI 校验），最后双通道部署（GitHub Pages + 自有 nginx 服务器）。这套「能被搜到 + 能留住询盘 + 好维护」的组合，正是 外贸独立站该有的样子。
